# Установка Black Titanium / Carbon — Galaxy S25 Ultra

1. Открой вкладку **Actions** в этом репозитории.
2. Найди последнюю успешную сборку **Build Black Titanium APK**.
3. Внизу страницы сборки скачай архив **BlackTitanium-S25Ultra-debug-APK**.
4. Распакуй архив на Samsung и открой **app-debug.apk**.
5. Android может попросить разрешить установку приложения из приложения «Мои файлы» или браузера. Разрешай только если доверяешь этому репозиторию и APK.
6. Запусти **Black Titanium**:
   - Кнопка **1** применяет карбоновые либо абсолютно чёрные обои.
   - Кнопка **2** откроет Theme Park. Выбери Icon → Create New → Iconpack → Third party icon packs → Black Titanium → Save → Apply.
   - Кнопка **3** покажет путь к Always On Display. Отключи **Показывать обои экрана блокировки**, включи часы, настрой тонкие белые цифры через редактор экрана блокировки.
   - Кнопка **4** объясняет, как добавить тёмный виджет.
   
**Важно:** Android не позволяет обычному приложению принудительно менять защищённые настройки AOD или значки системного лаунчера. Не нужно делать root или отключать защитные функции. Автоматически применяется только то, что разрешено через стандартный Android API.

Если GitHub Actions ещё не включён: открой Actions в репозитории и разреши выполнение рабочих процессов, затем запусти workflow.
